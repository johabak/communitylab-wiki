# Aruba

Aruba-dokumentasjonen stammer fra en workshop gjennomført i mai 2022. Sidene er foreløpig ikke publisert i hovedmenyen fordi miljøets tilgjengelighet og dokumentasjon må kvalitetssikres.

Workshopen omfattet blant annet Aruba ClearPass Policy Manager, Aruba Central og Aruba UXI.

## Før miljøet publiseres igjen

- bekreft hvilke produkter som fortsatt er tilgjengelige;
- kontroller at ClearPass-instansen kan brukes;
- avklar hvordan lokale aksesspunkter eller andre enheter skal kobles til;
- kontroller Teams-lenken og workshopguiden;
- dokumenter produktversjoner, begrensninger og ansvarlig kontakt.
