# Illumio

Illumio-området er under utvikling. Det finnes foreløpig ikke en ferdig veiledning eller et publisert labmiljø som kan tas i bruk fra denne wikien.

## Planlagt innhold

Området skal etter hvert beskrive:

- formålet med Illumio-laben;
- nødvendig programvare og kapasitet;
- foreslått nettverkstopologi;
- installasjon og grunnkonfigurasjon;
- tilkobling av arbeidslaster;
- opprettelse og testing av segmenteringspolicy;
- opprydding og tilbakestilling av miljøet.

## Status

| Egenskap | Informasjon |
| --- | --- |
| Status | Under utvikling |
| Tilgang | Ikke publisert |
| Veiledning | Ikke ferdigstilt |
| Hjelp | `Lab`-kanalen i Teams |

Har du erfaring med Illumio og ønsker å bidra, kan du dele forslag eller laboppsett i `Lab`-kanalen.
