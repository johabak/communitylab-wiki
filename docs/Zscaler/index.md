# Zscaler

Community Lab bruker Zscaler Solutions Demo Center som demonstrasjonsmiljø. Miljøet gir tidsbegrenset tilgang til flere Zscaler-tjenester og brukerprofiler.

## Kort fortalt

| Egenskap | Informasjon |
| --- | --- |
| Tilgang | Bestilles gjennom Zscalers partnerportal |
| Varighet | 30 dager om gangen |
| Fornyelse | Kan fornyes |
| Passer for | Utforsking av ZIA, ZPA, ZDX og sluttbrukeropplevelse |

[Kom i gang med Zscaler](zscaler_lab.md){ .md-button .md-button--primary }

## Hva kan du utforske?

- administratorportalene for ZIA, ZPA og ZDX;
- ulike sluttbrukerprofiler;
- klientbasert og klientløs tilgang;
- policyer og brukeropplevelse i et ferdig demonstrasjonsmiljø.

## Før du begynner

Du må kunne logge inn i Zscalers partnerportal. Tilgangen sendes på e-post og inneholder kontoer for både administratorer og sluttbrukere.

Bruk privat nettlesing når du bytter mellom brukerprofilene, og oppbevar påloggingsinformasjonen sikkert.
